# 🔥 Warmup Questions

Welcome to my **DSA Warmup Questions** collection.

This folder contains the basic programming and problem-solving questions I solve **before moving on to major coding platforms** such as **LeetCode, CodeChef, and Codeforces**.

These problems may look simple, but they are meant to strengthen the fundamentals required to solve more complex problems later.

---

## 🎯 Purpose

The goal of this section is to:

* 🧠 Build strong programming fundamentals
* 💡 Improve logical thinking and problem-solving
* 🔄 Get comfortable with loops, conditions, arrays, and basic mathematics
* 🛠️ Practice writing clean and efficient code
* 🚀 Prepare for more challenging DSA problems
* 📈 Build consistency before moving to competitive programming platforms
