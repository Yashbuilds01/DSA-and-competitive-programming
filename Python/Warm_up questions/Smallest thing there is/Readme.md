# 🔤 Smallest String There Is

## 📝 Problem

Given a positive integer `N`, construct a string of length `N` such that no two adjacent characters are the same.

Among all possible strings, find the **lexicographically minimum** string.

**Note:** You can use only lowercase characters from `'a'` to `'z'`.

**Difficulty:** Easy

**Time Limit:** 2 seconds  
**Memory Limit:** 256000 KB

## 📥 Input

The first and only line of input contains an integer `N`.

## 📌 Constraints

- `1 <= N <= 10^5`

## 📤 Output

Print the required string.
