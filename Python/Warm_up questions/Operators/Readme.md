# ➕ Operators

## 📝 Problem

Given two integers **a** and **b**, calculate and print the following four values:

- `a + b`
- `a - b`
- `a * b`
- `a / b`

Each result should be printed on a new line.

**Difficulty:** Easy

**Time Limit:** 2 seconds  
**Memory Limit:** 128000 KB

## 📥 Input

The input contains two integers `a` and `b` separated by a space.

## 📌 Constraints

- `1 ≤ b ≤ a ≤ 1000`
- It is guaranteed that `a` is divisible by `b`.

## 📤 Output

Print the results of the four operations, each on a new line, in the following order:

1. `a + b`
2. `a - b`
3. `a * b`
4. `a / b`

## 💡 Example

### Sample 1

**Input:**
```text
15 3
```

**Output:**
```text
18
12
45
5
```
