# Leap Year Check

## 📝 Problem Statement
Given a year `n` as an integer input, determine whether it is a leap year or not.

**Leap Year Rules:**
- A year is a leap year if it is a multiple of `4`.
- **Exception:** If the year is a multiple of `100`, it is **not** a leap year unless it is also a multiple of `400`.

---

## 📥 Input Format
- **User Task:** Complete the function `LeapYear(n)` that takes an integer `n` as a parameter.

## 📤 Output Format
- Print `YES` if the given year is a leap year.
- Print `NO` if it is not a leap year.

---

## ⚙️ Constraints
- 1 ≤ n ≤ 5000
- **Time Limit:** 2.0s
- **Memory Limit:** 256 MB
