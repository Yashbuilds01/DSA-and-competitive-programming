# 🔢 Check if Prime

## 📝 Problem

Given an integer, print whether that integer is a prime number or not.

**Difficulty:** Easy

**Time Limit:** 2 seconds  
**Memory Limit:** 256000 KB

## 📥 Input

The first line of input contains an integer `T`, representing the number of test cases.

Each test case contains a single integer `A`.

## 📌 Constraints

- `1 <= T <= 100`
- `1 <= A <= 10^8`

## 📤 Output

For each test case:

- Print `Yes` if the given integer is a prime number.
- Otherwise, print `No`.

## 💡 Examples

### Sample 1

**Input:**
```text
3
5
9
13
```

**Output:**
```text
Yes
No
Yes
```
