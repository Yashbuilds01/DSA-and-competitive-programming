# Doraemon's Division Gadget

## 📝 Problem Statement
Nobita wants to score well in his upcoming test, but he is not able to solve simple division problems. Seeing Nobita's determination, Doraemon gives him a gadget that can calculate division easily. However, Nobita accidentally deleted the internal program. 

Help Nobita write a program for his gadget that takes two integers `D` and `Q` and computes the value of `D / Q` rounded down (floor division).

> **Note:** Division by `0` is undefined and will cause a runtime error if not handled properly.

---

## 📥 Input Format
- A single line containing two space-separated integers representing `D` (Dividend) and `Q` (Divisor).

## 📤 Output Format
- Print the value of `D / Q` rounded down to the nearest integer.
- If the result is undefined (i.e., `Q = 0`), print `-1`.

---

## ⚙️ Constraints
- 0 ≤ D, Q ≤ 100
