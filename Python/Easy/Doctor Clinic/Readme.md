# Basic Arithmetic Operations

## 📝 Problem Statement
Given two integers `a` and `b`, your task is to calculate and print the following four arithmetic values in order:
1. **Addition (`a + b`)**
2. **Subtraction (`a - b`)**
3. **Multiplication (`a * b`)**
4. **Division (`a / b`)**

---

## 📥 Input Format
- The input consists of a single line containing two space-separated integers `a` and `b`.

## 📤 Output Format
- Print the result of each of the four operations (`a+b`, `a-b`, `a*b`, `a/b`), each on a new line.

---

## ⚙️ Constraints
- 1 ≤ b ≤ a ≤ 1000
- It is guaranteed that `a` will be evenly divisible by `b`.

---

## 💡 Example

### Sample Input
```text
15 3
