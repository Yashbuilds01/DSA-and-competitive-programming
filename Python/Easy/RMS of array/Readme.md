# 📐 RMS of an Array

## 📝 Problem

Given an array `A` of size `N`, find the **Root Mean Square (RMS)** of the array.

To calculate the RMS:

1. Square each element of the array.
2. Calculate the mean of the squared values.
3. Take the square root of the mean.

Print the answer with a precision of up to **6 decimal places**.

**Difficulty:** Easy

**Time Limit:** 2 seconds  
**Memory Limit:** 256000 KB

## 📥 Input

- The first line contains an integer `N`, representing the size of the array.
- The next line contains `N` space-separated integers representing the elements of the array.

## 📌 Constraints

- `1 <= N <= 100`
- `1 <= Ai <= 100`

## 📤 Output

Print the RMS value of the array with a precision of up to **6 decimal places**.

## 💡 Examples

### Sample 1

**Input:**
```text
4
1 2 3 4
```

**Output:**
```text
2.738613
```
