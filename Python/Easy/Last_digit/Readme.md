# 🔢 Last Digit

## 📝 Problem

Given an integer `N`, find and return the **last digit** of the given integer.

**Difficulty:** Easy

**Time Limit:** 2 seconds  
**Memory Limit:** 256000 KB

## 📥 Input

### User Task

Since this is a **functional problem**, you do not have to take input.

You only need to complete the function `LastDigit()` that takes an integer `N` as an argument.

## 📌 Constraints

- `1 <= N <= 10000`

## 📤 Output

Return the last digit of the given integer.

## 💡 Examples

### Sample 1

**Input:**
```text
123
```

**Output:**
```text
3
```
