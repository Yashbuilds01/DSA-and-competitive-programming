# Race (Naruto vs Sasuke)

## 📝 Problem Statement
Naruto and Sasuke are on an S-Rank mission. To pass the time, they decide to compete in a race on a horizontal plane toward a common destination spot `C`. 

Both of them run at the exact same speed. Given the initial positions of Naruto (`A`) and Sasuke (`B`), determine who will win the race (reach spot `C` first) or if it will end in a draw.

- Print `N` if Naruto wins.
- Print `S` if Sasuke wins.
- Print `D` if both reach the spot at the same time (Draw).

---

## 📥 Input Format
- **User Task:** Complete the function `Race(A, B, C)` which takes three space-separated integers as parameters:
  - `A`: Initial position of Naruto
  - `B`: Initial position of Sasuke
  - `C`: Position of the common spot

## 📤 Output Format
- Return the character `'N'`, `'S'`, or `'D'` corresponding to the outcome.

---

## ⚙️ Constraints
- 1 ≤ A, B, C ≤ 100
