# 🔢 Finite Input

## 📝 Problem

Take input from the standard input until you receive `0` as an input.

Print all the integers that were received, separated by a space.

It is guaranteed that the number of integers is less than `100000`.

**Difficulty:** Medium

**Time Limit:** 2 seconds  
**Memory Limit:** 256000 KB

## 📥 Input

The input contains a series of integers, with each integer provided on a separate line.

Continue taking input until `0` is received.

## 📌 Constraints

- `0 <= input <= 10`
- The total number of integers is less than `100000`.

## 📤 Output

Print all the input integers separated by a space.

The terminating `0` should also be included in the output.

## 💡 Examples

### Sample 1

**Input:**
```text
6
5
5
0
```

**Output:**

```text
6 5 5 0
```
